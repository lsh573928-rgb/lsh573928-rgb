### 👷 소개
경상북도 상주시 토목직 공무원입니다. 도로·배수·농업기반 시설의 자체설계(총공사비 3천만원 이하)를 하면서,
반복되는 야장 정리·도면·수량산출 작업을 코드로 자동화하고 있습니다.

### 🎬 시연 영상 (1분 38초)
<a href="https://github.com/lsh573928-rgb/sangju-estimate-public/blob/main/video/demo.mp4"><img src="https://raw.githubusercontent.com/lsh573928-rgb/sangju-estimate-public/main/video/poster.png" width="240" alt="시연 영상 — 한 건 설계 예전 3시간 → 지금 19초 + 담당자 확인"></a>

- 한 건 설계: 예전 3시간 → **지금 19초 + 담당자 확인**
- 실제 설계 33건(도면 190장)으로 규칙을 정리하고, 올해 실제 설계 9건에 사용 중
- 고칠 때마다 자동 검사 709개로 계산을 다시 확인

<sub>영상 속 마을·필지·항공영상·단가는 가상입니다. 그림을 누르면 영상이 열립니다.</sub>

### 🛠 하고 있는 일
- **소규모 건설공사 설계 자동화** — 야장 → 위치도·편입예상필지 조서 → 도면(DXF) → 수량산출서(xlsx) → 내역
  - 현장 사진의 GPS 위치가 그대로 노선 점이 되어 항공사진·지적 위에 올라갑니다
  - 실제 설계 건을 확정 내역서와 원 단위까지 맞춰 검증하며 규칙을 쌓습니다
  - 계산은 코드가, AI는 규칙 정리·검토·문서 작성을 맡습니다
  - 👉 [sangju-estimate-public](https://github.com/lsh573928-rgb/sangju-estimate-public)
- 업무용 GPTs 제작·배포, 공공부문 AI 학습 커뮤니티 운영
